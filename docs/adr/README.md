# Decisiones de arquitectura (ADR)

Un ADR registra una decisión importante y **por qué** se tomó, para que nadie
—ni humano ni agente— la deshaga sin saberlo.

Cuándo escribir uno: agregar una dependencia relevante, cambiar el modelo de
datos, cambiar la constitución o la infraestructura.

Formato: `NNNN-titulo-corto.md` con secciones *Contexto*, *Decisión*,
*Consecuencias* y *Alternativas descartadas* (ver `0001-...`).
